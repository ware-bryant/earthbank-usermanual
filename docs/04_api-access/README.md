# API Access

EarthBank provides a REST API so external software, scripts, and systems can read and write EarthBank-hosted data — for example, automated metadata upload from a lab's own systems, scripted data retrieval, or feeding EarthBank data into downstream synthesis and machine-learning workflows.

Full API documentation — authentication, endpoints, worked examples for reading and writing data — lives in a dedicated repository rather than here, so it can be maintained by and for developers without duplicating content:

**→ [io.lithosurfer.userdoc](https://github.com/lithodat-pty-ltd/io.lithosurfer.userdoc)**

Interactive (Swagger) API documentation is also available directly from the platform's Help menu once you're a registered Data Contributor.
