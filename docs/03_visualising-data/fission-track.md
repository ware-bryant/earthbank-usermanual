# Visualising Fission Track Data

1. Go to the Map window and confirm the relevant Data Package is switched on in the **Data Packages** panel (top left) — for example, the Australian Thermochronology Compilation.
2. Open **Analytical Layers** and select the Fission Track method of interest (e.g. apatite Fission Track).

The map colours sample locations by data type by default. Colour samples instead by **Age**, **Location Type**, **Rock Type**, **Elevation**, **Technique** (EDM, LA-ICP-MS), **Track Length** (mean track length, MTL), or **Track Length σ** (standard deviation of MTL) via the relevant filter control (see the [filter reference](../01_finding-and-viewing-data/map-window.md#filter-pop-ups)).

Hovering a sample shows its name, rock type, elevation, central age and age error, MTL and standard deviation, and technique.

## Sample detail

Clicking a sample opens a pop-up with detailed sample and Fission Track information, expandable into **Sample Data** and **Analytical Data** views. Where multiple samples share a locality, each has its own Sample Data / Analytical Data pair to select. The Analytical Data view includes plots such as a radial plot coloured by uranium concentration.

## Multi-sample selection

Use the polygon select tool (left toolbar) to draw around samples of interest — left-click to place each anchor point, right-click to close the polygon. The resulting window lists the selected samples and offers a shapefile download.

Switch between sample metadata and Fission Track dashboards via the dropdown at the top left. Each dashboard supports up to eight plot tiles, each independently configurable (data type, axis size, point colour) and exportable.

Use the multi-select tool to compare populations across geographic areas — for example, comparing Boomerang plots (age vs. MTL) across regions of Australia's passive continental margin.
