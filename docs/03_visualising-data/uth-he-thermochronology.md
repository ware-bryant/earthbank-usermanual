# Visualising (U-Th)/He Data

1. Go to the Map window and confirm the relevant Data Package is switched on in the **Data Packages** panel (top left). If it's not listed, open **Data Packages** to browse and enable one — for example, the Australian Thermochronology Compilation.
2. Open **Analytical Layers** and select the (U-Th)/He method of interest (e.g. apatite (U-Th)/He only).

Colour samples by **Rock Type**, **Location Type**, **Elevation**, **Age**, or **Interquartile Range (IQR)** via the relevant filter control (see the [filter reference](../01_finding-and-viewing-data/map-window.md#filter-pop-ups)).

Hovering a sample shows its name, rock type, elevation, mean corrected age, and corrected age error. Clicking a sample opens detailed sample and (U-Th)/He information, including plots such as eU vs. Corrected Single Grain Age. The sample can be exported as a shapefile with all its (U-Th)/He data.

## Multi-sample selection

Use the polygon select tool (left toolbar) to draw around samples of interest — left-click to place each anchor point, right-click to close the polygon. The resulting selection window lists all samples in the polygon and can be downloaded as a shapefile for use in other GIS software.

Switch between sample metadata and analytical data dashboards via the dropdown at the top left of the window. Each dashboard supports up to eight plot tiles; each tile has its own display and control settings (data type, axis size, point colour).

Plots are publication-ready and export via each tile's export control. Use the multi-select tool to define separate populations and compare trends across the dataset — for example, comparing sectors coloured by location.
