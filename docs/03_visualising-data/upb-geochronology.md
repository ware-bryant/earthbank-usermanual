# Visualising U-Pb Geochronology Data

## On the map

1. Open **Analytical Layers** and tick **U-Pb** to enable geochronology functionality.
2. Filter by location type, rock type, and analysis type, or by age using the colour-coded slider at the base of the map. The palette control lets you change the colour gradient used.

Under **Tools**, the interpolation tool creates an age interpolation map for a selected area; the Paleo Reconstruction tool (see [The Map Window](../01_finding-and-viewing-data/map-window.md#toolbar-tools)) shows samples in their paleogeographic context.

## Individual sample view

Clicking an individual sample (in geochronology mode) opens a pop-up with:

- A sample metadata summary table
- A geochronology data summary table
- Plots for that sample, scalable and exportable (JPEG, PNG, SVG, PDF) via the tile's controls, including: Wetherill plots, Tera-Wasserburg plots, weighted mean of the preferred isotopic date, histograms (preferred date, Th/U, U concentration), kernel density estimates, bivariate plots (isotopic ratios, dates, major/trace concentrations, Th/U), and radial plots

## Multi-sample selection

1. Select samples using **Select Area** — rectangle, polygon, or multi-select — to open the selections tab.
2. Optionally assign samples to populations via the dropdown.
3. Open **U-Pb** from the plotting dropdown to launch the plotting window, coloured by population.
4. Choose the number of plot tiles and set each tile's type/axes.
5. Export any tile via its export button.
