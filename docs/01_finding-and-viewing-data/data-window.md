# The Data Window

The Data window is the hub for browsing, filtering, and downloading samples and their associated data. Open it via the tab at the top right of the Map window. You can also upload data from here — see [Contributing Data](../02_contributing-data/README.md).

## Data landing page

The landing page combines a main content area (defaulting to **Start** for new users, or **Data Packages** thereafter) with a left-hand menu:

| Section | What it's for |
|---|---|
| **Start** | Platform video clips to help new users get oriented quickly |
| **Data Packages** | All Data Packages you can see — public ones, plus any where you're a Team Member. Data Packages are structured collections of data grouped by institution, project, or similar. Owners and Editors can upload, edit, and delete them; anyone can explore, filter, analyse, share, and download public ones. Each Data Package shows its name, description, sample count, analytical data types and volumes, images, files, team members, distribution (Public/Private), workflow state, and DOI — see [Data Packages](../02_contributing-data/data-packages.md). Contents download as a single ZIP — see [Filtering & Downloading](filtering-and-downloading.md) |
| **Samples** | Individual samples and their metadata, filterable at the sample level. Clicking a sample opens its landing page with further metadata and download options. Data Package owners/Editors can also add analytical data to a sample from here, via the relevant **Add … Data** option |
| **Analytical Data** | Geochemical/geochronological data for individual samples, browsable by data type |
| **Meta Data** | *(This section was still a placeholder in the source manual — to fill in once confirmed with the team)* |
| **Shared Data** | Cross-sample reference data: People, Literature, Funding, Archives, Reference Material, Rocks/Minerals, Labs, and Machines/Instruments |
