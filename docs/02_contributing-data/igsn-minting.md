# IGSN Minting

Data Contributors are strongly encouraged to mint an **International Generic Sample Number (IGSN)** for every geosample they upload. As the IGSN e.V. non-profit puts it:

> The application and long-term utility of sample based data is critically dependent on availability of information (metadata) about the samples, links to other data sets derived from individual samples, and access to the samples themselves... Using persistent identifiers for physical samples, such as the International Geo Sample Number (IGSN), provides solutions. The IGSN ID is a globally unique, persistent, domain-agnostic identifier for material samples.

## Minting an IGSN for one sample

Available either while creating/uploading a sample, or later, via the sample's **IGSN** tab. If the sample already has an IGSN, enter it manually. Otherwise, click **Mint** to open the Minting IGSNs pop-up:

| Field | Meaning |
|---|---|
| Sample Name | The sample name/ID you provided during upload |
| Namespace | Set for the whole platform via the minting DataCite member (Lithodat) |
| Proposed IGSN ID | Auto-suggested; you can instead specify your own 6–12 character string of capital letters and numbers (no spaces) — but auto-generation is recommended |

## Minting IGSNs for multiple samples

1. Open **Data**, select **Samples**.
2. Tick the checkboxes for the samples you want to mint.
3. Click **Batch Mint**.
4. The same Minting IGSNs pop-up appears as above.

Every minted sample gets a dedicated webpage, QR code, and citable DOI.
