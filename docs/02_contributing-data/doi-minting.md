# DOI Minting

EarthBank can generate a **Digital Object Identifier (DOI)** for a Data Package, giving it a permanent, citable reference and helping datasets meet publication requirements.

## Minting a DOI

**While creating a new Data Package:**

1. Open **Data**, select **Data Packages**, click **+ New**.
2. Name and describe the package, save, then open the **DOI** tab.
3. Click **Mint** to get a DOI instantly.

**For an existing Data Package:**

1. Open **Data Packages**, click the overflow menu on the package, open the **DOI** tab.
2. Click **Mint**, then save.

While you're there, you can also set **Distribution** (Public/Private) and **Workflow State** (In Progress/Finished/Frozen) from the Package Info tab — see [Data Packages](data-packages.md#data-privacy-control) and [Data Packages](data-packages.md#doi-workflow-state) for what each means.
