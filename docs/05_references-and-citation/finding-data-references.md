# Finding Data References

References for data on EarthBank can be found at the individual sample scale from either the Map window or the Data window.

## From the Map window

Select or filter samples as described in [Finding & Viewing Data](../01_finding-and-viewing-data/README.md). Once a sample is displayed, click it to open the sample information pop-up. If multiple samples share a location, a selection window opens first — click the sample ID you want to open its sample information window. The literature reference appears in a dropdown within that window, usually as a clickable link to the publication.

[SCREENSHOT: sample information pop-up with literature reference dropdown]

## From the Data window

Open the **Data** tab, select **Samples** from the left-hand menu, then search or filter (see [Filtering & downloading](../01_finding-and-viewing-data/filtering-and-downloading.md)) to find the sample you want. Click its row to open the sample landing page, where the data reference is a clickable link through to the literature window with further publication details.
