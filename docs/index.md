# EarthBank User Guide

Welcome to the user guide for **AuScope EarthBank** — an open data platform for the geochemistry community that lets you visualise, synthesise, disseminate, and extract geochemistry data in a global geospatial context.

Looking for the API instead of the platform's own interface? See the [EarthBank API documentation](https://github.com/lithodat-pty-ltd/io.lithosurfer.userdoc).
